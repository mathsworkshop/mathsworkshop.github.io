category: combi/counting

difficulty: 2
tags: linearity of expectation, indicator variables, permutations
date: 2026-11-04

## Statement

A permutation $\sigma$ of $\{1,\dots,n\}$ is chosen uniformly at random. Let $X$ be its number of fixed points ($\sigma(i)=i$).

1. Show that $\mathbb{E}[X]=1$ for every $n\ge1$.
2. Show that $\mathbb{E}[X(X-1)]=1$ for every $n\ge2$, and deduce the variance of $X$.

## Hint

Write $X=\sum_i I_i$ where $I_i$ is the indicator of the event "$\sigma(i)=i$". Expectation is additive even when the $I_i$ are dependent. For part 2, $X(X-1)$ counts ordered pairs of distinct fixed points.

## Solution

**1.** For each $i$, $\sigma(i)$ is uniformly distributed on $\{1,\dots,n\}$, so $\mathbb{E}[I_i]=\Pr[\sigma(i)=i]=\frac1n$. By linearity,
$$\mathbb{E}[X]=\sum_{i=1}^n\frac1n=1.$$

**2.** $X(X-1)=\sum_{i\ne j}I_iI_j$, the number of ordered pairs $(i,j)$, $i\ne j$, of fixed points. For $i\ne j$,
$$\Pr[\sigma(i)=i,\ \sigma(j)=j]=\frac{(n-2)!}{n!}=\frac1{n(n-1)}.$$
There are $n(n-1)$ ordered pairs, so $\mathbb{E}[X(X-1)]=n(n-1)\cdot\frac1{n(n-1)}=1$.

**Variance.** $\mathbb{E}[X^2]=\mathbb{E}[X(X-1)]+\mathbb{E}[X]=2$, so $\operatorname{Var}X=2-1^2=1$.

**Check.** For $n=5$ a computer enumeration of the $120$ permutations gives exactly $\mathbb{E}[X(X-1)]=1$.

**Remark.** The fixed points are far from independent (if $n-1$ points are fixed, so is the last one), yet linearity of expectation does not care. For $n=2$: $X$ is $2$ or $0$ with probability $\frac12$ each.

**Lesson.** Write the quantity as a sum of indicators and use linearity of expectation: no independence needed.

## Statement

A finite graph is **bipartite** if its vertices can be split into two classes such that every edge joins the two classes (equivalently, it can be coloured with $2$ colours so that adjacent vertices get different colours). Prove that a graph is bipartite if and only if it contains no cycle of odd length.

## Hint

For "if": in each connected component pick a root and colour each vertex by the parity of its distance to the root. If some edge joins two vertices of the same colour, build a closed walk of odd length, and show that an odd closed walk contains an odd cycle.

## Solution

**($\Rightarrow$)** Suppose the classes are $A$ and $B$. Going along a cycle, we alternate between $A$ and $B$, and we return to the start, so the number of steps is even.

**($\Leftarrow$)** Assume there is no odd cycle. It suffices to colour each connected component separately. In a component choose a root $r$ and give a vertex $x$ the colour of the parity of $d(x)$, the length of a shortest path from $r$ to $x$.

Suppose an edge $uv$ joins two vertices of the same parity. Then the walk "shortest path $r\to u$, the edge $uv$, shortest path $v\to r$" is a closed walk of length $d(u)+1+d(v)$, which is odd.

**Claim.** A closed walk of odd length contains an odd cycle.

*Proof by strong induction on the length $L$.* If no vertex repeats (except the start/end), the walk is a cycle, of odd length $L$. Otherwise some vertex $w$ occurs twice in the walk, which splits it into two closed walks (from $w$ to $w$) whose lengths $L_1,L_2$ are positive, smaller than $L$, and add up to $L$. One of them is odd; apply the induction hypothesis to it. $\square$

So the edge $uv$ would create an odd cycle, a contradiction. Hence every edge joins vertices of opposite parity, and the graph is bipartite.

**Example.** Trees, even cycles and grids have no odd cycle, so they can be $2$-coloured. A triangle needs $3$ colours.

**Lesson.** Colour by parity of distance; an odd closed walk always hides an odd cycle.

title: When can a graph be drawn without lifting the pen?
category: combi/graphs

## Statement

1. Prove that a connected graph in which every vertex has even degree has a closed trail (a walk that returns to its start and uses no edge twice) containing **all** its edges.
2. Deduce that a connected graph with exactly two vertices of odd degree has a trail using every edge exactly once, starting at one odd vertex and ending at the other.
3. For which $n$ does $K_n$ have a closed trail using every edge once?

## Hint

For part 1, take a trail with the largest possible number of edges and show that it must be closed and use all edges.

## Solution

**1.** Among all trails, take a longest one, $T=(v_0,v_1,\dots,v_m)$.

*$T$ is closed.* Suppose $v_m\ne v_0$. Each time $T$ passes through $v_m$ (other than the end) it uses two of its edges, and the last arrival uses one more, so $T$ uses an odd number of edges at $v_m$. Since $\deg v_m$ is even, there is an unused edge at $v_m$, and $T$ can be extended: contradiction. So $v_m=v_0$.

*$T$ uses all edges.* Suppose not. Because the graph is connected, some unused edge $e$ has an endpoint $w$ on $T$: take an unused edge $f$ and a path from a vertex of $T$ to an endpoint of $f$ ending with $f$; the first unused edge $e$ on this path starts at a vertex reached by used edges only. Rotate the closed trail $T$ so that it starts and ends at $w$, then append $e$: this is a longer trail, a contradiction.

**2.** Let $a,b$ be the odd vertices. Add a new edge $ab$ (a parallel edge if needed; the proof of part 1 works verbatim for multigraphs). All degrees are now even, so by part 1 there is a closed trail through all edges. Removing the new edge from it gives a trail from $a$ to $b$ through all the original edges exactly once.

**3.** All degrees of $K_n$ equal $n-1$. If $n$ is odd, the degrees are even and $K_n$ is connected, so a closed trail exists. If $n$ is even and $n\ge2$, every vertex has odd degree and a closed trail using all edges cannot exist. So the answer is: exactly the odd $n$ (for $n=1$ there are no edges and the empty trail works).

**Remark.** The converse of 1 is easy, so the condition is an equivalence. This is Euler's theorem (Königsberg bridges, 1736).

**Lesson.** Extremal choice: take a longest trail and show it cannot be improved.

title: Hall's marriage theorem and regular bipartite graphs
category: combi/graphs
level: olympiad
difficulty: 4
tags: Hall's theorem, matchings, bipartite graphs, induction
date: 2026-11-04
---

## Statement

Let $G$ be a finite bipartite graph with classes $A$ and $B$. For $S\subseteq A$, let $N(S)$ be the set of vertices of $B$ adjacent to at least one vertex of $S$.

1. (**Hall.**) Prove that $A$ can be matched into $B$ if and only if $|N(S)|\ge|S|$ for every $S\subseteq A$.
2. Deduce that a $k$-regular bipartite graph ($k\ge1$) has a perfect matching.
3. A deck of $52$ cards is dealt into $13$ piles of $4$ cards. Show that one can choose one card from each pile so that the $13$ chosen cards have all different ranks.

## Hint

For part 1 use induction on $|A|$, with two cases: either every proper nonempty $S$ has $|N(S)|\ge|S|+1$ (slack), or some proper nonempty $S$ has $|N(S)|=|S|$ (tight).

## Solution

**1.** ($\Rightarrow$) is clear: the $|S|$ partners of the vertices of $S$ are distinct elements of $N(S)$.

($\Leftarrow$) Induction on $|A|$; the case $|A|=1$ is clear. Assume Hall's condition.

*Case 1: $|N(S)|\ge|S|+1$ for every nonempty proper $S\subset A$.* Pick any $a\in A$ and any neighbour $b$ of $a$. Remove $a$ and $b$. For every nonempty $S\subseteq A\setminus\{a\}$, removing $b$ lowers the neighbourhood by at most $1$, so $|N'(S)|\ge|N(S)|-1\ge|S|$. By induction $A\setminus\{a\}$ can be matched, and we add the pair $\{a,b\}$.

*Case 2: some nonempty proper $S$ has $|N(S)|=|S|$.* The graph induced on $S\cup N(S)$ satisfies Hall's condition, so by induction $S$ is matched onto $N(S)$. In the rest of the graph,
$$|N(T)\setminus N(S)|=|N(T\cup S)|-|N(S)|\ge|T|+|S|-|S|=|T|.$$
So Hall's condition holds there and, by induction, $A\setminus S$ is matched. The two matchings together match $A$.

**2.** Counting edges, $k|A|=k|B|$, so $|A|=|B|$. For $S\subseteq A$, there are $k|S|$ edges leaving $S$, and they all end in $N(S)$, where each vertex receives at most $k$ of them. So $k|N(S)|\ge k|S|$. By Hall, $A$ is matched into $B$, and since $|A|=|B|$ this matching is perfect.

**3.** Let $A$ be the set of $13$ piles, $B$ the set of $13$ ranks. This is a $4$-regular bipartite multigraph. A perfect matching is exactly the required choice.

**Lesson.** To prove a matching exists, check Hall's condition; for regular graphs, double count edges.

## Statement

Let $n\ge2$. Show that the $2^n$ binary strings of length $n$ can be arranged in a cyclic list $g_1,g_2,\dots,g_{2^n}$ such that any two consecutive strings (including $g_{2^n}$ and $g_1$) differ in exactly one position.

## Hint

Build the list for $n$ from the list for $n-1$: write it forward with a $0$ in front, then backward with a $1$ in front.

## Solution

**Construction.** For $n=2$: $00,01,11,10$ works.

Suppose $g_1,\dots,g_m$ ($m=2^{n-1}$) is a valid cyclic list for length $n-1$. Define for length $n$ the list
$$0g_1,\,0g_2,\,\dots,\,0g_m,\,1g_m,\,1g_{m-1},\,\dots,\,1g_1.$$

**It contains every string once.** The first half contains all strings starting with $0$, the second half all those starting with $1$, each once.

**Consecutive strings differ in one position.**
- Inside the first half, $0g_i$ and $0g_{i+1}$ differ exactly where $g_i,g_{i+1}$ do.
- Inside the second half, same argument.
- At the middle, $0g_m$ and $1g_m$ differ only in the first position.
- Closing the cycle, $1g_1$ and $0g_1$ differ only in the first position.

By induction the list exists for every $n\ge2$.

**Explicit form.** The $k$-th string ($k=0,\dots,2^n-1$) can be taken to be the binary expansion of $k\oplus\lfloor k/2\rfloor$. Consecutive strings differ in one bit; and $k=2^n-1$ gives $10\cdots0$, which differs from the string $0$ for $k=0$ in one bit.

**Remark.** This is a Hamiltonian cycle in the $n$-dimensional cube graph. Gray codes are used in rotary encoders.

**Lesson.** "Reflect and prefix" constructions work for recursive structures; check the seams.

## Statement

1. How many ordered quadruples $(x_1,x_2,x_3,x_4)$ of integers satisfy $x_1+x_2+x_3+x_4=20$ and $1\le x_i\le8$ for every $i$?
2. Prove that the number of non-negative integer solutions of $y_1+\dots+y_k=m$ is $\binom{m+k-1}{k-1}$.

## Hint

Subtract $1$ from each variable to start at $0$. Count all solutions, then remove those with some variable $\ge8$ by inclusion-exclusion.

## Solution

**2. (Stars and bars.)** Write $m$ stars in a row and place $k-1$ bars among them; the bars cut the row into $k$ groups of stars whose sizes are $y_1,\dots,y_k\ge0$ with sum $m$, and every solution arises exactly once. A configuration is a sequence of $m+k-1$ symbols of which $k-1$ are bars: $\binom{m+k-1}{k-1}$ possibilities.

**1.** Put $y_i=x_i-1$, so $0\le y_i\le7$ and $y_1+\dots+y_4=16$.

- All non-negative solutions: $\binom{19}{3}=969$.
- Let $A_i$ be the set of solutions with $y_i\ge8$. Substituting $y_i=8+z_i$ gives $z$-sum $8$: $\binom{11}{3}=165$ solutions, for each $i$.
- Two variables $\ge8$: the sum would be $\ge16$ with equality: $y_i=y_j=8$ and the other two $0$, giving $\binom{3}{3}=1$ solution for each of the $\binom42=6$ pairs.
- Three variables $\ge8$ would need sum $\ge24>16$: impossible.

By inclusion-exclusion the answer is
$$969-4\cdot165+6\cdot1=315.$$

**Check.** Direct enumeration by computer gives $315$.

**Remark.** Equivalently, $315$ is the coefficient of $x^{16}$ in $\left(\frac{1-x^8}{1-x}\right)^4$.

**Lesson.** Stars and bars counts unconstrained solutions; upper bounds are handled by inclusion-exclusion on the violations.

## Statement

An **inversion** of a sequence $a_1,\dots,a_n$ of distinct numbers is a pair $i<j$ with $a_i>a_j$. Prove that the minimal number of swaps of two **adjacent** entries needed to sort the sequence into increasing order equals its number of inversions. What is the largest value this number can take for $n$ entries?

## Hint

How does one adjacent swap change the number of inversions? And if the sequence is not sorted, is there always a swap that reduces it?

## Solution

**Effect of a swap.** Swap $a_i$ and $a_{i+1}$. The relative order of this pair changes, so the pair is an inversion after the swap iff it was not before. Every other pair keeps the same relative order. So the number of inversions changes by exactly $\pm1$.

**Lower bound.** The sorted sequence has $0$ inversions. If the sequence has $I$ inversions, any sequence of swaps sorting it must decrease the count from $I$ to $0$ in steps of $\pm1$, so it has at least $I$ swaps.

**Upper bound.** If $I>0$, the sequence is not sorted, so there is an index $i$ with $a_i>a_{i+1}$. Swapping them decreases $I$ by $1$. Repeating, we sort the sequence in exactly $I$ swaps.

**Maximum.** The number of inversions is at most the number of pairs, $\binom n2$, with equality for the decreasing sequence.

**Example.** $5,4,3,2,1$ has $10$ inversions and needs $10$ swaps; $2,3,1$ has $2$ inversions.

**Remark.** The parity of the number of inversions is the sign of the permutation.

**Lesson.** A quantity that changes by exactly $\pm1$ per step (a monovariant) gives matching lower and upper bounds.

A king controls its own square and the (up to $8$) squares adjacent to it, including diagonally. What is the minimal number of kings that can be placed on an $8\times8$ chessboard so that every square is controlled?

For the lower bound, find many squares such that no single king can control two of them. For the upper bound, a king in the middle of a $3\times3$ block controls the whole block.

**Answer.** $9$.

**Remark.** For an $n\times n$ board the answer is $\lceil n/3\rceil^2$ by the same two arguments.

**Lesson.** To prove minimality, exhibit a set of "far apart" objects that each need their own resource.

## Statement

In an election, candidate $A$ receives $a$ votes and candidate $B$ receives $b$ votes, with $a>b$. The votes are counted in a uniformly random order. Prove that the probability that $A$ is **strictly ahead** of $B$ throughout the count is $\dfrac{a-b}{a+b}$.

## Hint

Represent the count as a sequence of $+1$ (vote for $A$) and $-1$ (vote for $B$). Bad sequences that start with $+1$ can be put in bijection with sequences starting with $-1$ by reflecting the part before the first tie.

## Solution

**Setup.** There are $\binom{a+b}a$ equally likely sequences of $a$ pluses and $b$ minuses. $A$ is strictly ahead throughout iff every partial sum is positive. Then the first vote must be $+1$.

**Sequences starting with $+1$.** There are $\binom{a+b-1}{a-1}$ of them. Among them, call a sequence **bad** if some partial sum equals $0$.

**Reflection.** Given a bad sequence, let $t$ be the first time its partial sum is $0$, and flip the signs of the first $t$ entries. The result starts with $-1$, and has the same total $a-b$. Conversely, every sequence starting with $-1$ and with total $a-b>0$ has a first time $t$ where its partial sum is $0$; flipping the first $t$ entries gives a bad sequence starting with $+1$. These maps are inverse to each other. Hence the number of bad sequences equals the number of sequences starting with $-1$ with $a$ pluses and $b$ minuses:
$$\binom{a+b-1}{a}.$$

**Counting.** The number of good sequences is
$$\binom{a+b-1}{a-1}-\binom{a+b-1}{a}=\binom{a+b}a\cdot\frac{a-b}{a+b}.$$

**Probability.** Dividing by $\binom{a+b}a$ gives $\dfrac{a-b}{a+b}$.

**Check.** For $a=5$, $b=3$ a direct count over all $56$ sequences gives probability $\frac14$.

**Lesson.** The reflection principle turns "paths that touch a line" into "paths ending elsewhere".

## Statement

A graph on $n$ vertices contains no cycle of length $4$.

1. Prove that $\displaystyle\sum_{v}\binom{d(v)}2\le\binom n2$, where $d(v)$ is the degree of $v$.
2. Deduce that a graph on $5$ vertices with no $4$-cycle has at most $6$ edges, and give an example with $6$ edges.

## Hint

Count pairs $\{x,y\}$ of vertices together with a common neighbour $v$. Two vertices can have at most one common neighbour.

## Solution

**1.** Count the pairs $(v,\{x,y\})$ where $x\ne y$ are both neighbours of $v$. For a fixed $v$ there are $\binom{d(v)}2$ pairs of neighbours, so the total is $\sum_v\binom{d(v)}2$.

Fix a pair $\{x,y\}$. If it had two distinct common neighbours $v,w$, then $x\,v\,y\,w$ would be a $4$-cycle. So each pair $\{x,y\}$ occurs for at most one $v$, and the total is at most $\binom n2$.

**2.** Let $n=5$ and suppose there are $e\ge7$ edges. The function $f(x)=\frac{x(x-1)}2$ is convex, so by Jensen's inequality
$$\sum_{v}f(d(v))\ge5f\left(\frac{2e}5\right)\ge5f\left(\frac{14}5\right)=12.6>10=\binom52,$$
contradicting part 1. So $e\le6$.

**Example with $6$ edges.** Take two triangles sharing one vertex $c$ (a "bowtie"): triangles $c,a,b$ and $c,d,e$. Every cycle lies inside one of the two triangles, because $c$ is the only vertex joining them. So there is no $4$-cycle.

**Remark.** The same method gives, for large $n$, that a $C_4$-free graph has at most about $\frac12n^{3/2}$ edges.

**Lesson.** Double count (vertex, pair of neighbours); forbidden configurations bound the count from above and convexity bounds it from below.

## Statement

Ten people sit around a round table. Each is either a **knight** (always tells the truth) or a **liar** (always lies). Each of them says: "Both my neighbours are liars." Find all possible numbers of knights.

## Hint

What does the statement of a knight force on his neighbours? What does the lie of a liar force?

## Solution

**Constraints.**
- A knight tells the truth, so both his neighbours are liars: no two knights are adjacent.
- A liar's statement is false, so at least one of his neighbours is a knight: no three consecutive liars.

Conversely, these two conditions are sufficient for consistency.

**Counting.** There is at least one knight. Let there be $k\ge1$ knights. Going around the circle, the knights split the remaining $10-k$ people into $k$ groups of consecutive liars. Each group has $1$ liar or $2$ liars (not $0$: knights are not adjacent; not $3$ or more: no three consecutive liars). Hence
$$k\le10-k\le2k\ \Longrightarrow\ \frac{10}3\le k\le5\ \Longrightarrow\ k\in\{4,5\}.$$

**Both values occur.**
- $k=5$: alternate knight, liar, knight, liar, ...
- $k=4$: groups of liars of sizes $2,2,1,1$ between the four knights ($4+2+2+1+1=10$).

**Answer.** $4$ or $5$ knights.

**Check.** A computer search over all $2^{10}$ assignments finds exactly the solutions with $4$ or $5$ knights.

**Lesson.** Turn each statement into a local constraint, then count blocks between the special elements.

## Statement

There are $n$ gas stations $S_1,\dots,S_n$ along a circular road, in this cyclic order. Station $S_i$ sells $g_i$ units of fuel and the stretch of road from $S_i$ to $S_{i+1}$ (with $S_{n+1}=S_1$) needs $d_i$ units of fuel. The total fuel available is at least the total fuel needed: $\sum g_i\ge\sum d_i$. A car with an empty tank (and unlimited tank capacity) starts at one of the stations, takes all the fuel there, and drives on. Show that one can choose the starting station so that the car completes the full circle without ever running out of fuel.

## Hint

Put $a_i=g_i-d_i$ and look at the partial sums $s_k=a_1+\dots+a_k$. Where should the car start relative to the smallest partial sum?

## Solution

**Setup.** Let $s_0=0$ and $s_k=a_1+\dots+a_k$, so that $s_n=\sum g_i-\sum d_i\ge0$. Let $m\in\{0,1,\dots,n-1\}$ be an index minimising $s_m$ among $s_0,\dots,s_{n-1}$. Start at station $S_{m+1}$.

**The car never runs out.** The fuel left on arrival at the station after having driven $k-m$ stretches is $s_k-s_m$ for $m<k\le n$, and $s_n-s_m+s_j$ after wrapping around.

- For $m<k\le n-1$ and $k=n$: $s_k-s_m\ge0$ because $s_m$ is the minimum of $s_0,\dots,s_{n-1}$ (for $k=n$ we use $s_n\ge0=s_0\ge s_m$).
- After wrapping: $s_n+s_j-s_m\ge s_j-s_m\ge0$.

All fuel-on-arrival amounts are non-negative, so the car never runs dry.

**Remark.** If $\sum g_i=\sum d_i$ the start is unique up to the stations where the minimum is attained. This is the cycle lemma.

**Lesson.** On a cycle, start right after the minimum of the prefix sums.

## Statement

Let $S$ be a finite set of at least $3$ points in the plane, **not all on one line**. Prove that there is a line passing through **exactly two** points of $S$.

## Hint

Consider all pairs consisting of a point $P\in S$ and a line $\ell$ through at least two points of $S$ with $P\notin\ell$. Choose the pair with the smallest distance from $P$ to $\ell$.

## Solution

**Choosing a minimal pair.** There are finitely many such pairs $(P,\ell)$, and at least one. Choose one for which the distance $h=\operatorname{dist}(P,\ell)>0$ is smallest. Let $Q$ be the foot of the perpendicular from $P$ to $\ell$.

**Claim.** The line $\ell$ contains exactly two points of $S$.

Suppose not: $\ell$ contains at least three points of $S$. Among them, at least two lie in one closed half-line of $\ell$ starting at $Q$. Call these two points $B$ and $C$, with $B$ between $Q$ and $C$ or $B=Q$, and $B\ne C$. Then $BC\le QC<PC$.

**A closer pair.** Consider the line $m=PC$, which contains the two points $P,C$ of $S$. The point $B$ is not on $m$. The distance from $B$ to $m$ is
$$\operatorname{dist}(B,m)=BC\sin\angle PCQ=BC\cdot\frac{h}{PC}<h,$$
because $BC<PC$. So the pair $(B,m)$ has a smaller distance than $(P,\ell)$, contradicting the choice.

Therefore $\ell$ passes through exactly two points of $S$. $\square$

**Remark.** This is Kelly's proof (1948) of a conjecture of Sylvester. The statement is false in the projective plane (the Fano plane has $7$ points and every line has $3$), which shows that the proof must use distances.

## Statement

Let $p$ be an odd prime. Prove that the number of subsets of $\{1,2,\dots,p\}$ whose sum of elements is divisible by $p$ is
$$\frac{2^p+2(p-1)}p.$$

## Hint

Let $\omega=e^{2\pi i/p}$. Then $\frac1p\sum_{j=0}^{p-1}\omega^{jt}$ equals $1$ if $p\mid t$ and $0$ otherwise. Apply this to the sum of each subset and exchange the order of summation.

## Solution

**Roots of unity filter.** Let $N$ be the number we want. For a subset $A$ with sum $\Sigma(A)$,
$$\frac1p\sum_{j=0}^{p-1}\omega^{j\Sigma(A)}=\begin{cases}1&p\mid\Sigma(A)\\0&\text{otherwise,}\end{cases}$$
so
$$N=\frac1p\sum_{j=0}^{p-1}\sum_{A}\omega^{j\Sigma(A)}=\frac1p\sum_{j=0}^{p-1}\prod_{k=1}^p\bigl(1+\omega^{jk}\bigr).$$

**The term $j=0$** gives $2^p$.

**The terms $j=1,\dots,p-1$.** The residues $jk$ modulo $p$ run over all residues exactly once, so
$$\prod_{k=1}^p(1+\omega^{jk})=\prod_{r=0}^{p-1}(1+\omega^r).$$
From $\prod_{r=0}^{p-1}(x-\omega^r)=x^p-1$ at $x=-1$:
$$\prod_{r=0}^{p-1}(1+\omega^r)=2.$$

**Conclusion.**
$$N=\frac1p\bigl(2^p+(p-1)\cdot2\bigr)=\frac{2^p+2(p-1)}p.$$

**Check.** $p=3$: $\frac{8+4}3=4$. $p=5$: $8$. $p=7$: $20$.

**Remark.** As a corollary, $2^p\equiv2\pmod p$, a proof of Fermat's little theorem for base $2$.

**Lesson.** To count objects with a divisibility condition, average a root of unity over the residues.

## Statement

$$e(G)\le\left(1-\frac1r\right)\frac{n^2}2.$$

## Hint

Induct on $r$. Take a vertex $v$ of maximum degree $\Delta$ and split the vertices into the neighbourhood $A$ of $v$ and the rest $B$. What do you know about the graph induced on $A$?

## Solution

**Idea.** The neighbours of a vertex of largest degree form a graph with no $K_r$; the outside vertices have degree at most $\Delta$.

**Base case $r=1$.** No $K_2$ means no edge, and the bound is $0$ ✓.

**Induction step.** Let $r\ge2$ and assume the statement for $r-1$. Let $v$ have maximum degree $\Delta$, let $A=N(v)$ ($|A|=\Delta$) and $B=V\setminus A$ ($|B|=n-\Delta$).

Adding,
$$e(G)\le\frac{r-2}{r-1}\cdot\frac{\Delta^2}2+(n-\Delta)\Delta=n\Delta-\frac r{2(r-1)}\Delta^2.$$

**Maximising over $\Delta$.** The right side is a concave quadratic in $\Delta$, maximal at $\Delta=\frac{(r-1)n}r$, where its value is
$$\frac{(r-1)n^2}{2r}=\left(1-\frac1r\right)\frac{n^2}2.$$
So $e(G)\le\left(1-\frac1r\right)\frac{n^2}2$ ∎.

**Sharpness.** Splitting the vertices into $r$ equal groups and joining vertices of different groups gives a $K_{r+1}$-free graph with this many edges when $r\mid n$. For $r=2$ this is Mantel's theorem.

For $i=1,\dots,k-1$ the two arcs $I_i$ and $I_{i-k}$ are consecutive blocks of $k$ positions, hence disjoint because $2k\le n$. $$N=|\mathcal F|\cdot n\,k!\,(n-k)!\le k\cdot n!\ \Longrightarrow\ |\mathcal F|\le\frac kn\binom nk=\binom{n-1}{k-1}.$$
∎

**Sharpness.** All $k$-sets containing the element $1$ form an intersecting family of size $\binom{n-1}{k-1}$.

The total number of squares decreases at each turn, so eventually the opponent is left with the poisoned square.

**Lesson.** When pigeonhole directly fails, build a cleverly chosen label for each object so that distinct objects get distinct labels.

## Statement

## Hint

If $u$ and $v$ are adjacent, can they have a common neighbour? Deduce a bound on $d(u)+d(v)$, then sum over all edges.

## Solution

**Idea.** Count the pairs (vertex, edge containing it) in two ways.

**Local bound.** Let $uv$ be an edge. If a vertex $w$ were adjacent to both $u$ and $v$, then $uvw$ would be a triangle. So the neighbourhoods of $u$ and $v$ are disjoint, and
$$d(u)+d(v)\le n.$$

**Summation.** Let $e$ be the number of edges. Summing over all edges $uv$,
$$\sum_{uv\in E}\bigl(d(u)+d(v)\bigr)\le ne.$$
On the left, each vertex $v$ appears $d(v)$ times, each with the term $d(v)$. So the left side equals $\sum_vd(v)^2$:
$$\sum_vd(v)^2\le ne.$$

**Cauchy–Schwarz.** Since $\sum_vd(v)=2e$,
$$\sum_vd(v)^2\ge\frac{\left(\sum_vd(v)\right)^2}n=\frac{4e^2}n.$$

**Conclusion.** $\dfrac{4e^2}n\le ne$, so $e\le\dfrac{n^2}4$.

**Equality.** For $n$ even, the complete bipartite graph $K_{n/2,n/2}$ is triangle-free with $\frac{n^2}4$ edges. For $n$ odd, the bound is $\left\lfloor\frac{n^2}4\right\rfloor$ and is attained by $K_{(n-1)/2,(n+1)/2}$.

**Lesson.** Double counting: when a sum over edges involves degrees, rewrite it as a sum over vertices; combine with Cauchy–Schwarz.

$$\binom nk\binom n{n-k}=\binom nk^2,$$
using $\binom n{n-k}=\binom nk$. Summing over $k$ gives the left side.

**Check.** $n=3$: $1+9+9+1=20=\binom63$.

**Generalisation.** Vandermonde's identity $\sum_k\binom mk\binom n{r-k}=\binom{m+n}r$.

**Lesson.** Double counting: to prove an identity, find a set whose size can be computed in two different ways.

## Statement

A path of length $2n$ starts at height $0$ and at each step goes up by $1$ or down by $1$. Prove that the number of such paths that end at height $0$ and never go below height $0$ is
$$C_n=\frac1{n+1}\binom{2n}n.$$

## Hint

Count all paths from $0$ to $0$, then subtract the bad ones. For a bad path, reflect the part before the first visit to height $-1$.

## Solution

**Idea.** The reflection principle: bad paths are in bijection with paths that are easy to count.

**All paths.** A path from $0$ to $0$ with $2n$ steps has $n$ up-steps and $n$ down-steps, so there are $\binom{2n}n$ of them.

**Bad paths.** A path from $0$ to $0$ is bad if it reaches height $-1$ at some moment. Consider the first such moment $t$, and reflect the portion of the path before $t$ about the line $y=-1$. The new path starts at $-2$, still reaches $-1$ first at time $t$, and ends at $0$.

Conversely, any path from $-2$ to $0$ with $2n$ steps must cross $-1$; reflecting the part before the first visit to $-1$ gives a bad path from $0$ to $0$. These operations are inverse, so bad paths are in bijection with all paths from $-2$ to $0$.

**Counting those.** A path from $-2$ to $0$ in $2n$ steps has $u$ up-steps and $d$ down-steps with $u+d=2n$ and $u-d=2$: $u=n+1$, $d=n-1$. So there are $\binom{2n}{n+1}$ of them.

**Conclusion.**
$$C_n=\binom{2n}n-\binom{2n}{n+1}=\frac1{n+1}\binom{2n}n.$$
The first values are $1,2,5,14,42,132,\dots$

**Remark.** The same numbers count well-formed sequences of $n$ pairs of brackets and triangulations of a convex $(n+2)$-gon.

**Lesson.** Reflection principle: reflect an initial segment to transform a constrained count into an unconstrained one.

## Statement

The squares of an $n\times n$ board ($n\ge2$) are all white. A move chooses one row or one column and changes the colour of every square in it. Prove that it is impossible to obtain a board with exactly one black square.

## Hint

Look at a $2\times2$ block formed by two rows and two columns, and count its black squares modulo $2$.

## Solution

**Idea.** Find a quantity that no move can change.

**Invariant.** Fix two rows $r\ne r'$ and two columns $c\ne c'$, and consider the four squares $(r,c),(r,c'),(r',c),(r',c')$. Look at the parity of the number of black squares among these four.
- A move on row $r$ (or $r'$) changes exactly two of them.
- A move on column $c$ (or $c'$) likewise changes exactly two.
- A move on any other row or column changes none of them.

Changing two squares changes their black count by $-2$, $0$ or $+2$: the parity of the black count is invariant.

**Conclusion.** At the start this number is $0$, so it stays even forever. Now suppose a board with a single black square $(a,b)$ could be reached. Choose any other row $r'\ne a$ and column $c'\ne b$ and the block of the rows $a,r'$ and columns $b,c'$: it contains exactly one black square, an odd number. Contradiction.

**Remark.** The reachable boards are exactly those in which every $2\times2$ block has an even number of black squares.

**Lesson.** Invariant: restrict attention to a small sub-configuration on which each move acts in a controlled way.

## Statement

Among $N$ coins, exactly one is heavier than the others, which all have the same weight. You may use a balance scale (comparing the weights of two groups, with three possible outcomes: left heavier, right heavier, balance).

1. Prove that if $N=3^k$, the heavy coin can always be found in $k$ weighings.
2. Prove that if $N>3^k$, it is not always possible to find it in $k$ weighings.

## Hint

For part 1, divide the coins into three equal groups. For part 2, count the possible sequences of outcomes.

## Solution

**1. Strategy.** Induction on $k$. For $k=0$ there is a single coin. For $k\ge1$, divide the $3^k$ coins into three groups $A,B,C$ of $3^{k-1}$ coins and weigh $A$ against $B$.
- If $A$ is heavier, the heavy coin is in $A$; if $B$ is heavier, it is in $B$.
- If the scale balances, it is in $C$.

In each case, the heavy coin is among $3^{k-1}$ coins, which can be found in $k-1$ further weighings by the induction hypothesis. In total $k$ weighings suffice.

**2. Lower bound.** Fix a strategy using at most $k$ weighings. Each possible heavy coin gives a sequence of at most $k$ outcomes, each outcome being one of $3$ values. There are at most $3^k$ such sequences.

If two different coins gave the same sequence, the strategy could not tell them apart. So a strategy that always finds the coin must give distinct sequences to distinct coins, hence $N\le3^k$. Therefore $N>3^k$ coins cannot be handled in $k$ weighings.

**Remark.** An information-theoretic argument: each weighing provides at most $\log_23$ bits of information. The harder variant with a coin that may be heavier or lighter is solved by the same principle: $12$ coins in $3$ weighings.

**Lesson.** Optimal algorithm problems come in two halves: an explicit strategy, and a counting argument on outcomes showing that nothing better is possible.
