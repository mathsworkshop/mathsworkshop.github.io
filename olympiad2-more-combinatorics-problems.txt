category: olympiad/oly-combinatorics
level: m1
difficulty: 2
tags: linearity of expectation, indicator variables, permutations
date: 2026-11-04

## Statement

A permutation $\sigma$ of $\{1,\dots,n\}$ is chosen uniformly at random. Let $X$ be its number of fixed points ($\sigma(i)=i$).

1. Show that $\mathbb{E}[X]=1$ for every $n\ge1$.
2. Show that $\mathbb{E}[X(X-1)]=1$ for every $n\ge2$, and deduce the variance of $X$.

## Hint

Write $X=\sum_i I_i$ where $I_i$ is the indicator of the event "$\sigma(i)=i$". Expectation is additive even when the $I_i$ are dependent. For part 2, $X(X-1)$ counts ordered pairs of distinct fixed points.

## Solution

**1.** For each $i$, $\sigma(i)$ is uniformly distributed on $\{1,\dots,n\}$, so $\mathbb{E}[I_i]=\Pr[\sigma(i)=i]=\frac1n$. By linearity,
$$\mathbb{E}[X]=\sum_{i=1}^n\frac1n=1.$$

**2.** $X(X-1)=\sum_{i\ne j}I_iI_j$, the number of ordered pairs $(i,j)$, $i\ne j$, of fixed points. For $i\ne j$,
$$\Pr[\sigma(i)=i,\ \sigma(j)=j]=\frac{(n-2)!}{n!}=\frac1{n(n-1)}.$$
There are $n(n-1)$ ordered pairs, so $\mathbb{E}[X(X-1)]=n(n-1)\cdot\frac1{n(n-1)}=1$.

**Variance.** $\mathbb{E}[X^2]=\mathbb{E}[X(X-1)]+\mathbb{E}[X]=2$, so $\operatorname{Var}X=2-1^2=1$.

**Check.** For $n=5$ a computer enumeration of the $120$ permutations gives exactly $\mathbb{E}[X(X-1)]=1$.

**Remark.** The fixed points are far from independent (if $n-1$ points are fixed, so is the last one), yet linearity of expectation does not care. For $n=2$: $X$ is $2$ or $0$ with probability $\frac12$ each.

**Lesson.** Write the quantity as a sum of indicators and use linearity of expectation: no independence needed.

title: A graph is bipartite exactly when it has no odd cycle

## Statement

A finite graph is **bipartite** if its vertices can be split into two classes such that every edge joins the two classes (equivalently, it can be coloured with $2$ colours so that adjacent vertices get different colours). Prove that a graph is bipartite if and only if it contains no cycle of odd length.

## Hint

For "if": in each connected component pick a root and colour each vertex by the parity of its distance to the root. If some edge joins two vertices of the same colour, build a closed walk of odd length, and show that an odd closed walk contains an odd cycle.

## Solution

**($\Rightarrow$)** Suppose the classes are $A$ and $B$. Going along a cycle, we alternate between $A$ and $B$, and we return to the start, so the number of steps is even.

**($\Leftarrow$)** Assume there is no odd cycle. It suffices to colour each connected component separately. In a component choose a root $r$ and give a vertex $x$ the colour of the parity of $d(x)$, the length of a shortest path from $r$ to $x$.

Suppose an edge $uv$ joins two vertices of the same parity. Then the walk "shortest path $r\to u$, the edge $uv$, shortest path $v\to r$" is a closed walk of length $d(u)+1+d(v)$, which is odd.

**Claim.** A closed walk of odd length contains an odd cycle.

*Proof by strong induction on the length $L$.* If no vertex repeats (except the start/end), the walk is a cycle, of odd length $L$. Otherwise some vertex $w$ occurs twice in the walk, which splits it into two closed walks (from $w$ to $w$) whose lengths $L_1,L_2$ are positive, smaller than $L$, and add up to $L$. One of them is odd; apply the induction hypothesis to it. $\square$

So the edge $uv$ would create an odd cycle, a contradiction. Hence every edge joins vertices of opposite parity, and the graph is bipartite.

**Example.** Trees, even cycles and grids have no odd cycle, so they can be $2$-coloured. A triangle needs $3$ colours.

**Lesson.** Colour by parity of distance; an odd closed walk always hides an odd cycle.

title: When can a graph be drawn without lifting the pen?

## Statement

1. Prove that a connected graph in which every vertex has even degree has a closed trail (a walk that returns to its start and uses no edge twice) containing **all** its edges.
2. Deduce that a connected graph with exactly two vertices of odd degree has a trail using every edge exactly once, starting at one odd vertex and ending at the other.
3. For which $n$ does $K_n$ have a closed trail using every edge once?

## Hint

For part 1, take a trail with the largest possible number of edges and show that it must be closed and use all edges.

## Solution

**1.** Among all trails, take a longest one, $T=(v_0,v_1,\dots,v_m)$.

*$T$ is closed.* Suppose $v_m\ne v_0$. Each time $T$ passes through $v_m$ (other than the end) it uses two of its edges, and the last arrival uses one more, so $T$ uses an odd number of edges at $v_m$. Since $\deg v_m$ is even, there is an unused edge at $v_m$, and $T$ can be extended: contradiction. So $v_m=v_0$.

*$T$ uses all edges.* Suppose not. Because the graph is connected, some unused edge $e$ has an endpoint $w$ on $T$: take an unused edge $f$ and a path from a vertex of $T$ to an endpoint of $f$ ending with $f$; the first unused edge $e$ on this path starts at a vertex reached by used edges only, and all used edges have both endpoints on $T$ (or $e$ starts at the vertex of $T$ where the path begins). Rotate the closed trail $T$ so that it starts and ends at $w$, then append $e$: this is a longer trail, a contradiction.

**2.** Let $a,b$ be the odd vertices. Add a new edge $ab$ (a parallel edge if needed; the proof of part 1 works verbatim for multigraphs). All degrees are now even, so by part 1 there is a closed trail through all edges. Removing the new edge from it gives a trail from $a$ to $b$ through all the original edges exactly once.

**3.** All degrees of $K_n$ equal $n-1$. If $n$ is odd, the degrees are even and $K_n$ is connected, so a closed trail exists. If $n$ is even and $n\ge2$, every vertex has odd degree and a closed trail using all edges cannot exist (it would use an even number of edges at each vertex). So the answer is: exactly the odd $n$ (for $n=1$ there are no edges and the empty trail works).

**Remark.** The converse of 1 is easy (a closed trail uses an even number of edges at each vertex), so the condition is an equivalence. This is Euler's theorem (Königsberg bridges, 1736).

**Lesson.** Extremal choice: take a longest trail and show it cannot be improved.

title: Hall's marriage theorem and regular bipartite graphs

date: 2026-11-04

## Statement

Let $G$ be a finite bipartite graph with classes $A$ and $B$. For $S\subseteq A$, let $N(S)$ be the set of vertices of $B$ adjacent to at least one vertex of $S$.

1. (**Hall.**) Prove that $A$ can be matched into $B$ (every vertex of $A$ is paired with a distinct neighbour) if and only if $|N(S)|\ge|S|$ for every $S\subseteq A$.
2. Deduce that a $k$-regular bipartite graph ($k\ge1$; every vertex has degree $k$) has a perfect matching.
3. A deck of $52$ cards is dealt into $13$ piles of $4$ cards. Show that one can choose one card from each pile so that the $13$ chosen cards have all different ranks.

## Hint

For part 1 use induction on $|A|$, with two cases: either every proper nonempty $S$ has $|N(S)|\ge|S|+1$ (slack), or some proper nonempty $S$ has $|N(S)|=|S|$ (tight).

## Solution

**1.** ($\Rightarrow$) is clear: the $|S|$ partners of the vertices of $S$ are distinct elements of $N(S)$.

($\Leftarrow$) Induction on $|A|$; the case $|A|=1$ is clear. Assume Hall's condition.

*Case 1: $|N(S)|\ge|S|+1$ for every nonempty proper $S\subset A$.* Pick any $a\in A$ and any neighbour $b$ of $a$ (it exists since $|N(\{a\})|\ge1$). Remove $a$ and $b$. For every nonempty $S\subseteq A\setminus\{a\}$, $S$ is a proper subset of $A$, and removing $b$ lowers the neighbourhood by at most $1$, so $|N'(S)|\ge|N(S)|-1\ge|S|$. By induction $A\setminus\{a\}$ can be matched, and we add the pair $\{a,b\}$.

*Case 2: some nonempty proper $S$ has $|N(S)|=|S|$.* The graph induced on $S\cup N(S)$ satisfies Hall's condition (neighbourhoods of subsets of $S$ lie in $N(S)$), so by induction $S$ is matched onto $N(S)$. In the rest of the graph (classes $A\setminus S$ and $B\setminus N(S)$), for $T\subseteq A\setminus S$,
$$|N(T)\setminus N(S)|=|N(T\cup S)|-|N(S)|\ge|T|+|S|-|S|=|T|.$$
So Hall's condition holds there and, by induction, $A\setminus S$ is matched. The two matchings together match $A$.

**2.** Let $|A|$ and $|B|$ be the sizes of the classes. Counting edges, $k|A|=k|B|$, so $|A|=|B|$. For $S\subseteq A$, there are $k|S|$ edges leaving $S$, and they all end in $N(S)$, where each vertex receives at most $k$ of them. So $k|N(S)|\ge k|S|$, i.e. $|N(S)|\ge|S|$. By Hall, $A$ is matched into $B$, and since $|A|=|B|$ this matching is perfect.

**3.** Let $A$ be the set of $13$ piles, $B$ the set of $13$ ranks, and join a pile to a rank if the pile contains a card of that rank. Each pile has $4$ cards, so degree $4$ (counting multiplicities); each rank appears on exactly $4$ cards. This is a $4$-regular bipartite multigraph (the proof of part 2 works verbatim with multiple edges). A perfect matching is exactly the required choice.

**Lesson.** To prove a matching exists, check Hall's condition; for regular graphs, double count edges.

title: Gray codes: a cyclic list of all bit strings with one change at a time

## Statement

Let $n\ge2$. Show that the $2^n$ binary strings of length $n$ can be arranged in a cyclic list $g_1,g_2,\dots,g_{2^n}$ such that any two consecutive strings (including $g_{2^n}$ and $g_1$) differ in exactly one position.

## Hint

Build the list for $n$ from the list for $n-1$: write it forward with a $0$ in front, then backward with a $1$ in front.

## Solution

**Construction.** For $n=2$: $00,01,11,10$ works (and $10\to00$ closes the cycle).

Suppose $g_1,\dots,g_m$ ($m=2^{n-1}$) is a valid cyclic list for length $n-1$. Define for length $n$ the list
$$0g_1,\,0g_2,\,\dots,\,0g_m,\,1g_m,\,1g_{m-1},\,\dots,\,1g_1.$$

**It contains every string once.** The first half contains all strings starting with $0$, the second half all those starting with $1$, each once.

**Consecutive strings differ in one position.**
- Inside the first half, $0g_i$ and $0g_{i+1}$ differ exactly where $g_i,g_{i+1}$ do: one position.
- Inside the second half, same argument.
- At the middle, $0g_m$ and $1g_m$ differ only in the first position.
- Closing the cycle, $1g_1$ and $0g_1$ differ only in the first position.

By induction the list exists for every $n\ge2$.

**Explicit form.** The $k$-th string ($k=0,\dots,2^n-1$) can be taken to be the binary expansion of $k\oplus\lfloor k/2\rfloor$ (bitwise XOR). Indeed, if $k$ has $t$ trailing ones, $k\oplus(k+1)=2^{t+1}-1$ and $\lfloor k/2\rfloor\oplus\lfloor(k+1)/2\rfloor=2^t-1$, so consecutive strings differ in the single bit $2^t$; and $k=2^n-1$ gives $10\cdots0$, which differs from the string $0$ for $k=0$ in one bit.

**Remark.** This is a Hamiltonian cycle in the $n$-dimensional cube graph (vertices: bit strings, edges: strings differing in one bit). Gray codes are used in rotary encoders so that a small movement never changes more than one bit.

**Lesson.** "Reflect and prefix" constructions work for recursive structures; check the seams.

## Solution

**2. **Remark.** Equivalently, $315$ is the coefficient of $x^{16}$ in $\left(\frac{1-x^8}{1-x}\right)^4$.

title: Sorting by adjacent swaps needs exactly the number of inversions

## Statement

An **inversion** of a sequence $a_1,\dots,a_n$ of distinct numbers is a pair $i<j$ with $a_i>a_j$. Prove that the minimal number of swaps of two **adjacent** entries needed to sort the sequence into increasing order equals its number of inversions. What is the largest value this number can take for $n$ entries?

## Hint

How does one adjacent swap change the number of inversions? And if the sequence is not sorted, is there always a swap that reduces it?

## Solution

**Effect of a swap.** Swap $a_i$ and $a_{i+1}$. The relative order of this pair changes, so the pair is an inversion after the swap iff it was not before. Every other pair keeps the same relative order (for another element $x$, its position relative to both of them is unchanged). So the number of inversions changes by exactly $\pm1$.

**Lower bound.** The sorted sequence has $0$ inversions. If the sequence has $I$ inversions, any sequence of swaps sorting it must decrease the count from $I$ to $0$ in steps of $\pm1$, so it has at least $I$ swaps.

**Upper bound.** If $I>0$, the sequence is not sorted, so there is an index $i$ with $a_i>a_{i+1}$ (an adjacent inversion; otherwise the sequence is increasing). Swapping them decreases $I$ by $1$. Repeating, we sort the sequence in exactly $I$ swaps.

**Maximum.** The number of inversions is at most the number of pairs, $\binom n2$, with equality for the decreasing sequence. So at most $\binom n2$ swaps are ever needed.

**Example.** $5,4,3,2,1$ has $10$ inversions and needs $10$ swaps; $2,3,1$ has $2$ inversions and sorts as $2,3,1\to2,1,3\to1,2,3$.

**Remark.** The parity of the number of inversions is the sign of the permutation: each swap flips it.

**Lesson.** A quantity that changes by exactly $\pm1$ per step (a monovariant) gives matching lower and upper bounds.

category: olympiad/oly-combinatorics

difficulty: 4
tags: ballot problem, reflection principle, lattice paths, probability
date: 2026-11-04

## Statement

In an election, candidate $A$ receives $a$ votes and candidate $B$ receives $b$ votes, with $a>b$. The votes are counted in a uniformly random order. Prove that the probability that $A$ is **strictly ahead** of $B$ throughout the count is $\dfrac{a-b}{a+b}$.

## Hint

Represent the count as a sequence of $+1$ (vote for $A$) and $-1$ (vote for $B$). Bad sequences that start with $+1$ can be put in bijection with sequences starting with $-1$ by reflecting the part before the first tie.

## Solution

**Setup.** There are $\binom{a+b}a$ equally likely sequences of $a$ pluses and $b$ minuses. $A$ is strictly ahead throughout iff every partial sum is positive. Then the first vote must be $+1$.

**Sequences starting with $+1$.** There are $\binom{a+b-1}{a-1}$ of them. Among them, call a sequence **bad** if some partial sum equals $0$.

**Reflection.** Given a bad sequence, let $t$ be the first time its partial sum is $0$, and flip the signs of the first $t$ entries. The result starts with $-1$, and has the same total $a-b$ (the flipped prefix had sum $0$). Conversely, every sequence starting with $-1$ and with total $a-b>0$ has a first time $t$ where its partial sum is $0$ (steps are $\pm1$, from $-1$ up to a positive final value); flipping the first $t$ entries gives a bad sequence starting with $+1$. These maps are inverse to each other (the first zero time is unchanged by flipping the prefix). Hence the number of bad sequences equals the number of sequences starting with $-1$ with $a$ pluses and $b$ minuses:
$$\binom{a+b-1}{a}.$$

**Counting.** The number of good sequences is
$$\binom{a+b-1}{a-1}-\binom{a+b-1}{a}=\binom{a+b}a\left(\frac a{a+b}-\frac b{a+b}\right)=\binom{a+b}a\cdot\frac{a-b}{a+b},$$
using $\binom{a+b-1}{a-1}=\frac a{a+b}\binom{a+b}a$ and $\binom{a+b-1}a=\frac b{a+b}\binom{a+b}a$.

**Probability.** Dividing by $\binom{a+b}a$ gives $\dfrac{a-b}{a+b}$.

**Check.** For $a=5$, $b=3$ a direct count over all $56$ sequences gives probability $\frac14=\frac{5-3}{5+3}$.

**Lesson.** The reflection principle turns "paths that touch a line" into "paths ending elsewhere".

title: Graphs with no 4-cycle

level: olympiad
difficulty: 4
tags: extremal graph theory, double counting, convexity, cycles

## Statement

A graph on $n$ vertices contains no cycle of length $4$.

1. Prove that $\displaystyle\sum_{v}\binom{d(v)}2\le\binom n2$, where $d(v)$ is the degree of $v$.
2. Deduce that a graph on $5$ vertices with no $4$-cycle has at most $6$ edges, and give an example with $6$ edges.

## Hint

Count pairs $\{x,y\}$ of vertices together with a common neighbour $v$. Two vertices can have at most one common neighbour.

## Solution

**1.** Count the pairs $(v,\{x,y\})$ where $x\ne y$ are both neighbours of $v$. For a fixed $v$ there are $\binom{d(v)}2$ pairs of neighbours, so the total is $\sum_v\binom{d(v)}2$.

Fix a pair $\{x,y\}$. If it had two distinct common neighbours $v,w$, then $x\,v\,y\,w$ would be a $4$-cycle. So each pair $\{x,y\}$ occurs for at most one $v$, and the total is at most $\binom n2$.

**2.** Let $n=5$ and suppose there are $e\ge7$ edges. The function $f(x)=\frac{x(x-1)}2$ is convex, so by Jensen's inequality
$$\sum_{v}f(d(v))\ge5f\left(\frac{2e}5\right)\ge5f\left(\frac{14}5\right)=5\cdot\frac{2.8\cdot1.8}2=12.6>10=\binom52,$$
using that $f$ is increasing for $x\ge1$ and $\frac{2e}5\ge2.8$. This contradicts part 1, so $e\le6$.

**Example with $6$ edges.** Take two triangles sharing one vertex $c$ (a "bowtie"): triangles $c,a,b$ and $c,d,e$. It has $5$ vertices and $6$ edges. Every cycle lies inside one of the two triangles, because $c$ is the only vertex joining them (a cycle through $a$ or $b$ that left the triangle $cab$ would have to leave and re-enter through $c$, repeating a vertex). So every cycle is a triangle and there is no $4$-cycle.

**Remark.** The same method gives, for large $n$, that a $C_4$-free graph has at most about $\frac12n^{3/2}$ edges.

**Lesson.** Double count (vertex, pair of neighbours); forbidden configurations bound the count from above and convexity bounds it from below.

## Statement

Ten people sit around a round table. Each is either a **knight** (always tells the truth) or a **liar** (always lies). Each of them says: "Both my neighbours are liars." Find all possible numbers of knights.

## Hint

What does the statement of a knight force on his neighbours? What does the lie of a liar force?

## Solution

**Constraints.**
- A knight tells the truth, so both his neighbours are liars: no two knights are adjacent.
- A liar's statement is false, so it is not true that both his neighbours are liars: **at least one of his neighbours is a knight**. So no liar has two liar neighbours: no three consecutive liars.

Conversely, these two conditions are sufficient for the statements to be consistent.

**Counting.** There is at least one knight (if everyone were a liar, a liar's statement would be true). Let there be $k\ge1$ knights. Going around the circle, the knights split the remaining $10-k$ people into $k$ groups of consecutive liars, one between each pair of consecutive knights (cyclically). Each group has $1$ liar or $2$ liars (not $0$: knights are not adjacent; not $3$ or more: no three consecutive liars). Hence
$$k\le10-k\le2k\ \Longrightarrow\ \frac{10}3\le k\le5\ \Longrightarrow\ k\in\{4,5\}.$$

**Both values occur.**
- $k=5$: alternate knight, liar, knight, liar, ... (all groups of size $1$).
- $k=4$: groups of liars of sizes $2,2,1,1$ between the four knights ($4+2+2+1+1=10$).

**Answer.** $4$ or $5$ knights.

**Check.** A computer search over all $2^{10}$ assignments finds exactly the solutions with $4$ or $5$ knights.

**Lesson.** Turn each statement into a local constraint, then count blocks between the special elements.

## Statement

There are $n$ gas stations $S_1,\dots,S_n$ along a circular road, in this cyclic order. Station $S_i$ sells $g_i$ units of fuel and the stretch of road from $S_i$ to $S_{i+1}$ (with $S_{n+1}=S_1$) needs $d_i$ units of fuel. The total fuel available is at least the total fuel needed: $\sum g_i\ge\sum d_i$. A car with an empty tank (and an unlimited tank capacity) starts at one of the stations, takes all the fuel there, and drives on, taking all the fuel at each station it reaches. Show that one can choose the starting station so that the car completes the full circle without ever running out of fuel.

## Hint

Put $a_i=g_i-d_i$ and look at the partial sums $s_k=a_1+\dots+a_k$. Where should the car start relative to the smallest partial sum?

## Solution

**Setup.** Let $s_0=0$ and $s_k=a_1+\dots+a_k$, so that $s_n=\sum g_i-\sum d_i\ge0$. Let $m\in\{0,1,\dots,n-1\}$ be an index minimising $s_m$ among $s_0,\dots,s_{n-1}$. Start at station $S_{m+1}$.

**The car never runs out.** The fuel left when the car arrives at the station after having driven $k-m$ stretches is $s_k-s_m$ for $m<k\le n$, and, after wrapping around, $s_n-s_m+s_j$ for the stations $j=1,\dots,m$ (so $k=n+j$).

- For $m<k\le n-1$ and $k=n$: $s_k-s_m\ge0$ because $s_m$ is the minimum of $s_0,\dots,s_{n-1}$ (for $k=n$ we need $s_n-s_m\ge0$, which holds since $s_n\ge0=s_0\ge s_m$).
- After wrapping: $s_n+s_j-s_m\ge s_j-s_m\ge0$, since $s_n\ge0$ and $s_j\ge s_m$.

All the amounts of fuel on arrival are non-negative, so the car never runs dry (the fuel needed for each stretch is available at departure: fuel after refuelling minus $d_k$ is the fuel on arrival, which is $\ge0$).

**Remark.** If $\sum g_i=\sum d_i$ the start is unique up to the stations where the minimum is attained. This is the cycle lemma, also behind the ballot problem and Catalan numbers.

**Lesson.** On a cycle, start right after the minimum of the prefix sums.

title: The Sylvester-Gallai theorem
category: olympiad/oly-combinatorics
level: olympiad
difficulty: 5
tags: combinatorial geometry, extremal principle, distance, lines
date: 2026-11-04
---

## Statement

Let $S$ be a finite set of at least $3$ points in the plane, **not all on one line**. Prove that there is a line passing through **exactly two** points of $S$.

## Hint

Consider all pairs consisting of a point $P\in S$ and a line $\ell$ through at least two points of $S$ with $P\notin\ell$. Choose the pair with the smallest distance from $P$ to $\ell$.

## Solution

**Choosing a minimal pair.** There are finitely many such pairs $(P,\ell)$, and at least one (the points are not all collinear). Choose one for which the distance $h=\operatorname{dist}(P,\ell)>0$ is smallest. Let $Q$ be the foot of the perpendicular from $P$ to $\ell$.

**Claim.** The line $\ell$ contains exactly two points of $S$.

Suppose not: $\ell$ contains at least three points of $S$. Among them, at least two lie in one closed half-line of $\ell$ starting at $Q$ (three points, two sides: by pigeonhole, two of them lie on the same side of $Q$, or one of them is $Q$ itself and we use the closed half-line). Call these two points $B$ and $C$, with $B$ between $Q$ and $C$ or $B=Q$, and $B\ne C$. Then $QC>0$ and $BC\le QC<PC$, the last inequality because $PQC$ is a right triangle with hypotenuse $PC$.

**A closer pair.** Consider the line $m=PC$, which contains the two points $P,C$ of $S$. The point $B$ is not on $m$ (the line $m$ meets $\ell$ only at $C$, and $B\ne C$). The distance from $B$ to $m$ is
$$\operatorname{dist}(B,m)=BC\sin\angle PCQ=BC\cdot\frac{h}{PC}<h,$$
because $BC<PC$. So the pair $(B,m)$ has a smaller distance than $(P,\ell)$, contradicting the choice.

Therefore $\ell$ passes through exactly two points of $S$. $\square$

**Remark.** This is Kelly's proof (1948) of a conjecture of Sylvester (1893), first proved by Gallai. The statement is false in the projective plane (the Fano plane has $7$ points and every line has $3$), which shows that the proof must use distances.

**Lesson.** The extremal principle: pick the configuration minimising a quantity and show that a smaller one exists unless the structure is special.

title: Subsets whose sum is divisible by p

## Statement

Let $p$ be an odd prime. Prove that the number of subsets of $\{1,2,\dots,p\}$ (including the empty set) whose sum of elements is divisible by $p$ is
$$\frac{2^p+2(p-1)}p.$$

## Hint

Let $\omega=e^{2\pi i/p}$. Then $\frac1p\sum_{j=0}^{p-1}\omega^{jt}$ equals $1$ if $p\mid t$ and $0$ otherwise. Apply this to the sum of each subset and exchange the order of summation.

## Solution

**Roots of unity filter.** Let $N$ be the number we want. For a subset $A$ with sum $\Sigma(A)$,
$$\frac1p\sum_{j=0}^{p-1}\omega^{j\Sigma(A)}=\begin{cases}1&p\mid\Sigma(A)\\0&\text{otherwise,}\end{cases}$$
so
$$N=\frac1p\sum_{j=0}^{p-1}\sum_{A}\omega^{j\Sigma(A)}=\frac1p\sum_{j=0}^{p-1}\prod_{k=1}^p\bigl(1+\omega^{jk}\bigr),$$
because $\sum_A\omega^{j\Sigma(A)}=\prod_{k=1}^p(1+\omega^{jk})$ (each element $k$ is either left out, contributing $1$, or included, contributing $\omega^{jk}$).

**The term $j=0$** gives $2^p$.

**The terms $j=1,\dots,p-1$.** Since $p$ is prime and $p\nmid j$, the residues $jk$ ($k=1,\dots,p$) modulo $p$ run over all residues $0,1,\dots,p-1$ exactly once, so
$$\prod_{k=1}^p(1+\omega^{jk})=\prod_{r=0}^{p-1}(1+\omega^r).$$
From $\prod_{r=0}^{p-1}(x-\omega^r)=x^p-1$ at $x=-1$:
$$\prod_{r=0}^{p-1}(-1-\omega^r)=(-1)^p-1=-2,$$
and $\prod(1+\omega^r)=(-1)^p\cdot(-2)=2$ since $p$ is odd.

**Conclusion.**
$$N=\frac1p\bigl(2^p+(p-1)\cdot2\bigr)=\frac{2^p+2(p-1)}p.$$

**Check.** $p=3$: $\frac{8+4}3=4$, and the subsets $\varnothing,\{3\},\{1,2\},\{1,2,3\}$ have sums $0,3,3,6$. $p=5$: $\frac{32+8}5=8$; $p=7$: $\frac{128+12}7=20$ (confirmed by computer).

**Remark.** As a corollary, $p\mid2^p+2(p-1)$, i.e. $2^p\equiv2\pmod p$: a proof of Fermat's little theorem for the base $2$. A similar computation solves IMO 1995 Problem 6.

**Lesson.** To count objects with a divisibility condition, average a root of unity over the residues.

## Statement

A random ordering of $n$ different numbers is presented one at a time. A **record** is a number larger than all the numbers before it (the first number is always a record). Prove that the expected number of records is the harmonic number $H_n=1+\frac12+\dots+\frac1n$.

## Hint

Let $I_k$ be the indicator that the $k$-th number is a record. Compare the $k$-th number with the first $k-1$ ones: what is the probability that it is the largest of the first $k$?

## Solution

**Indicators.** Let $I_k=1$ if the $k$-th number is a record, and $0$ otherwise. The number of records is $R=I_1+\dots+I_n$.

**Probability of $I_k=1$.** The $k$-th number is a record iff it is the largest among the first $k$ numbers. By symmetry (all orderings are equally likely), each of the first $k$ numbers is equally likely to be the largest of them, so
$$\Pr[I_k=1]=\frac1k.$$

**Linearity.**
$$\mathbb{E}[R]=\sum_{k=1}^n\frac1k=H_n.$$

**Check.** For $n=5$, enumerating all $120$ permutations gives total $274$ records, i.e. the mean $\frac{274}{120}=\frac{137}{60}=H_5$.

**Remark.** The indicators $I_1,\dots,I_n$ are even independent, so $\operatorname{Var}R=\sum\frac1k\left(1-\frac1k\right)$. Since $H_n\approx\ln n+0.577$, records are rare: among $1000$ numbers one expects only about $7.5$ records. This is the basis of the "secretary problem" strategy.

**Lesson.** Use symmetry to compute the probability of each indicator, then add.

## Statement

1. Show that for $n\ge1$ the number of surjective maps from an $n$-element set onto a $3$-element set is $3^n-3\cdot2^n+3$.
2. Deduce the number $S(n,3)$ of ways to split an $n$-element set into $3$ nonempty unlabelled groups, and show in particular that $3^n-3\cdot2^n+3$ is divisible by $6$.
3. Prove also that $S(n,2)=2^{n-1}-1$.

## Hint

Count all maps and subtract those missing at least one value (inclusion-exclusion). Each partition into $3$ groups corresponds to exactly $3!$ surjections.

## Solution

**1.** Let the target be $\{1,2,3\}$. There are $3^n$ maps. Let $A_i$ be the set of maps never taking the value $i$; $|A_i|=2^n$, $|A_i\cap A_j|=1$ for $i\ne j$ (every element goes to the third value), and $|A_1\cap A_2\cap A_3|=0$ (as $n\ge1$). By inclusion-exclusion the number of maps missing no value is
$$3^n-3\cdot2^n+3\cdot1-0.$$

**2.** A surjection $f$ gives the partition $\{f^{-1}(1),f^{-1}(2),f^{-1}(3)\}$ into three nonempty groups, and each partition arises from exactly $3!=6$ surjections (the ways to label the groups with $1,2,3$). Hence
$$S(n,3)=\frac{3^n-3\cdot2^n+3}6,$$
which is an integer, so $6\mid3^n-3\cdot2^n+3$.

**3.** A map onto $\{1,2\}$ is surjective unless it is constant: $2^n-2$ surjections, and each partition into $2$ groups comes from $2$ surjections. So $S(n,2)=\frac{2^n-2}2=2^{n-1}-1$.

**Check.** For $n=3$: $\frac{27-24+3}6=1$ (one way: three singletons); $n=4$: $\frac{81-48+3}6=6$; $n=7$: $\frac{2187-384+3}6=301$. All agree with direct enumeration.

**Remark.** In general, the number of surjections onto a $k$-set is $\sum_{j=0}^k(-1)^j\binom kj(k-j)^n=k!\,S(n,k)$.

**Lesson.** Count labelled objects (surjections) by inclusion-exclusion, then divide by the symmetry of the labels.
